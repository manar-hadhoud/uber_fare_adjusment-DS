# Uber Fare Prediction Project

## Overview

This project focuses on analyzing and predicting Uber fares in New York City (NYC) using a dataset of 193,708 trip records from 2009 to 2015. The project involves data preparation, cleansing, exploratory data analysis (EDA), machine learning experimentation, and fare prediction using regression models. The final deliverable includes visualizations and a trained model for fare prediction, along with a React-based UI for user interaction.

The repository contains scripts for data analysis, model training, UI development, and saved models. The primary dataset used is `uber.csv`, which includes trip details like fare amounts, pickup/dropoff coordinates, and timestamps.

---

## Repository Structure

- **DATA_ANALYSIS/**: Directory containing scripts and data for analysis.
  - `uber_analysis.ipynb`: Jupyter notebook for data preparation, cleansing, and initial analysis.
  - `uber_DA.zip`: Zipped file containing the `uber.csv` dataset used for analysis.
- **MODEL_TRAIN/**: Directory for model training scripts and data.
  - `Uber.ipynb`: Jupyter notebook for model training, evaluation, and hyperparameter tuning.
  - `uber.zip`: Zipped file containing additional data or scripts used for training (if applicable).
- **plots/**: Directory for generated visualizations (currently empty in the repository).
- **react_ui/uber-fare-ui/**: Directory for the React-based UI application.
  - `__pycache__/`: Python cache directory (likely autogenerated, can be ignored).
  - `node_modules/`: Directory for Node.js dependencies (autogenerated after `npm install`).
  - `public/`: Directory for public assets of the React app.
  - `src/`: Directory for the React app source code.
  - `.gitignore`: Git ignore file for the React app.
  - `package-lock.json`: Lock file for Node.js dependencies.
  - `package.json`: Configuration file for the React app.
- **best_lgb_model.pkl**: Saved LightGBM model for fare prediction.
- **coordinate_bounds.pkl**: Pickle file containing NYC coordinate bounds for data filtering.
- **lgb_model.pkl**: Alternative saved LightGBM model (possibly a different version).
- **main.py**: Python script (likely for running predictions or serving the model).
- **model_features.pkl**: Pickle file containing the list of features used for model training.
- **README.md**: This file, providing an overview and instructions for the project.
- **scaler.pkl**: Pickle file containing the trained scaler for feature preprocessing.
